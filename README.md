# Distribucion

Plataforma externa para clientes, revendedores, mayoristas y distribuidores autorizados.

Este proyecto consume datos del ERP principal mediante API. El ERP sigue siendo la fuente de verdad para catalogo, SKUs, imagenes, categorias, marcas, atributos, listas de precios, inventario, estados operativos, aprobaciones y permisos comerciales.
